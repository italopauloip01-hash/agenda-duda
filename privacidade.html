Política de Privacidade

Agenda Beleza · atualizada em 17 de outubro de 2026

O Agenda Beleza é um aplicativo de agenda para profissionais de beleza (manicure, pedicure, podologia, cabeleireiras e afins). Esta política explica quais dados usamos, por quê e como você controla isso.

1. Quem usa o app

Profissionais criam uma conta (com e-mail e senha ou com a conta Google) para gerenciar a própria agenda. Clientes das profissionais podem agendar pelo link público, informando nome, WhatsApp e, se quiserem, uma observação.

2. Dados que guardamos

  • Conta da profissional: e-mail, nome e, se usar o Google, o identificador da conta Google.
  • Dados do negócio cadastrados pela profissional: clientes (nome, telefone, aniversário, preferências), agendamentos, serviços, pagamentos, despesas, estoque, avaliações, fotos do portfólio e mensagens prontas.
  • Agendamento online: nome, WhatsApp e observação informados pela cliente, que viram um agendamento na conta da profissional escolhida.

Cada conta é isolada: uma profissional não tem acesso aos dados de outra. O isolamento é aplicado no próprio banco de dados.

3. Uso dos dados do Google

Se a profissional entrar com a conta Google e autorizar, o app pode:

  • Contatos (somente leitura): listar os contatos para que ela escolha quais importar como clientes. Só os contatos marcados por ela são salvos.
  • Calendário (agendas criadas pelo app): criar uma agenda própria do app na conta Google dela e criar, alterar ou apagar nessa agenda os eventos dos agendamentos. O app não lê nem altera as outras agendas.
  • Disponibilidade (livre/ocupado): consultar apenas os horários ocupados da agenda principal, sem ver títulos ou detalhes dos compromissos, para não oferecer horários em que ela já está ocupada.

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de dados do usuário dos serviços de API do Google, incluindo os requisitos de Uso Limitado. Os dados do Google são usados somente para as funções acima, não são vendidos, não são usados para publicidade e não são compartilhados com terceiros, exceto quando necessário para operar o app (hospedagem) ou exigido por lei.

4. Onde os dados ficam

Os dados ficam armazenados com criptografia em trânsito no provedor de banco de dados Supabase. O acesso ao Google é guardado de forma protegida no servidor e nunca é exposto no navegador de outras pessoas.

5. Seus direitos (LGPD)

  • Você pode ver, corrigir e apagar os dados cadastrados pelo próprio app.
  • Você pode desconectar o Google a qualquer momento em Ajustes → Conta Google → Desconectar, ou em myaccount.google.com/permissions.
  • Para excluir a conta e todos os dados, ou se você é cliente e quer que seus dados sejam apagados, escreva para o contato abaixo.
